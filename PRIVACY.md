# ArrowKeys privacy policy

## macOS

ArrowKeys works offline. It does not record what you type, collect personal data, send analytics or use tracking services.

The Mac App Store edition registers eight shortcuts with macOS. When you allow cursor control, the app sends the corresponding navigation keys to the foreground app. It keeps each keyboard’s previous modifier assignments in the app’s local preferences until it restores them. This lets it recover an assignment the next time it starts after an interrupted session.

The edition distributed directly on GitHub uses Accessibility permission to recognize the shortcuts locally. It keeps the previous Caps Lock assignment in memory until it restores it.

Both editions save setup and login preferences on your Mac so they remember your choices.

## Windows

ArrowKeys processes keyboard input on your PC to turn its shortcuts into cursor movements. The app does not record what you type, collect personal information, send telemetry, display ads or use the network. Text entered in the shortcut guide is held in memory and disappears when the app exits.

The Microsoft Store edition saves a local flag after it first shows the shortcut guide. Windows enables startup at sign-in when you first open the app. You can turn it off in Settings → Apps → Startup. Uninstalling removes the startup task and the app's local package data.

You can ask questions through the project's [support page](https://github.com/nauroman/arrowkeys/issues).

Choosing a GitHub link opens your web browser. GitHub handles that visit under its own privacy policy.
